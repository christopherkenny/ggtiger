# Princeton Color Palette

Princeton Color Palette

## Usage

``` r
princeton
```

## Format

A list of
[palette::palette](http://christophertkenny.com/palette/reference/palette.md)
vectors

## Examples

``` r
princeton$core
#> <palette[13]>
#>  [1] #e98338 #092264 #89130d #5b0f58 #19460e #aac7da #d9d1cb #d9d7e6 #d5deda
#> [10] #7cdaf3 #f5a5f9 #c9a7fa #8ae168
```
